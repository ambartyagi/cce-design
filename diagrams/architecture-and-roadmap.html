2 · The compounding loop the product, in one cycle

Every use case in every domain is an instance of this cycle. It is what the 14-check demo exercises, and what every later phase makes richer — never different.
AskAgent compiles context: retrieve → precedence → inject. Attribution records exactly which object versions entered the answer.
Answer + citeGrounded response citing certified objects. Decision trace stored — reproducible, auditable.
Correct → proposeUser or agent flags a miss. Correction becomes a proposal with rationale, risk class, and impact preview.
Certify → supersedeHuman (or policy, when low-risk) certifies. New version materializes; old version retained as history; change log appended.
↻ Next ask is permanently better — and the eval harness's golden set guarantees a certified correction never regresses.
